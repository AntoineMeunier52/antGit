# antGit

**antGit** is a minimalist reimplementation of Git, designed to explore and understand how Git works under the hood.

## ✅ Features

### Implemented

- `git init` – Initialize a new antGit repository
- `git commit` – In progress: commit current changes to the repository

---

## 🔮 Upcoming Features

- `git branch` – Implement a basic branching system
